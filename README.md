# StackUp

Landing page da StackUp, uma formação full-stack apresentada em uma interface
interativa e responsiva. O projeto foi desenvolvido com React, TypeScript e Vite.

## Requisitos

- Node.js
- npm

## Como executar

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

## Outros comandos

```bash
npm run build    # Gera a versão de produção em dist/
npm run preview  # Pré-visualiza a versão de produção
npm run format   # Formata os arquivos com oxfmt
```
